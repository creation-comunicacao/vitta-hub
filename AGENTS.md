# VITTA HUB — contexto de continuidade

Antes de implementar ou revisar páginas, consulte `docs/REFERENCIAS-E-DECISOES.md`, `docs/PLANO-E-ACEITE.md` e as seções relevantes de `docs/fontes/`. O briefing integral inicial está em `docs/BRIEFING.md`.

Preserve FITNESS PERSONAL como marca principal, VITTA HUB como estrutura integrada e B2B condomínios como prioridade comercial. Hubs são divisões B2B. M.I.V.A. é metodologia transversal. Nutrição precede suplementação.

Confirmações do usuário prevalecem sobre versões documentais anteriores. Não invente dados, preços, fotos de clientes/equipe, qualificações ou resultados. Não trate referências documentais como autorização para publicar ou enviar mensagens.

O projeto é revisado em três partes. A base da parte 3 está implementada e em revisão. Por solicitação expressa do usuário, somente o backend dos formulários usa PHP. Todo o frontend permanece React/TypeScript/Tailwind. npm run dev inicia o frontend 5173 e a API PHP 8789; exportação opcional para Locaweb via build:locaweb. Consulte docs/LOCAWEB.md e docs/VERIFICACAO-PARTE-3.md. Atualize registros de decisões e verificações ao concluir cada parte.
